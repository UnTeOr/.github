## Development Philosophy

UTG uses a systems-oriented approach to technology.

Rather than starting with code alone, we begin with the problem, the people involved, the desired outcome, and the relationships between each part of the system.

AI-assisted development — sometimes called **vibe coding** — allows us to move rapidly from concept to prototype while continuously testing, refining, and simplifying the user experience.
